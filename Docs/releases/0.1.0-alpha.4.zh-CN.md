本次更新加入自动 CASEVAC 救援，并明确默认战地治疗边界。

- 同时开启战地救援与 CASEVAC 工作后，会优先自动搬运无人负责的患者，再加入已有队伍或升级附近的 SAR 送床搬运。修复队员归属、协助者速度判断、床位预约清理及与医生的预约竞争。没有可用床位时，回退为单人搬运到指定救援点。
- 战地治疗集中处理流血及已适配的急症，包括危险感染与 More Injuries 的早期低血容量休克。小伤留到安全床位或救援点后处理，专门的紧急干预仍可执行。
- 在医生工作下加入高优先级的紧急医疗子工作。配合 Work Tab，可让专职急救员仅执行急救，把常规治疗和手术留给其他医生。
- 改善多个医疗模组同时启用时的行为，包括逐伤口药品规则、共享血液与设备预算、外部医疗接管和 CE 补给保护。兼容面板继续按单个模组展示。

已通过 21 模组环境实测、自动调度回归、CASEVAC 实际跟随与送床、预约生命周期以及途中失去床位的回退检查。各联动仍需启用对应模组；仅单独分配医生子工作需要 Work Tab。
